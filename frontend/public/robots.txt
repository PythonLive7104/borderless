# TryNoBot — https://trynobot.com
# The marketing site is open to crawlers. Everything behind a login, the API,
# and the bot-handling pages are not: they are per-visitor responses with no
# search value, and indexing a decoy page would be actively misleading.
#
# /login and /signup are deliberately NOT listed. They are linked from every
# page, so disallowing them only made Search Console report them as "blocked by
# robots.txt" forever — a block it can never validate away, because nothing is
# broken. Keeping them crawlable lets Google read the <meta name="robots"
# content="noindex"> that the SPA shell already serves, which is what actually
# keeps a page out of the index. A page has to be crawlable to be told noindex.

User-agent: *
Allow: /$
Disallow: /dashboard/
Disallow: /admin/
Disallow: /api/
Disallow: /l/
Disallow: /reset-password/
Disallow: /verify-email
Disallow: /accept-invite
Disallow: /decoy.html
Disallow: /blocked.html
Disallow: /not-found.html
Disallow: /unauthorized.html

# good ClickCease alternative" is the same job the comparison pages do in
# search, and these crawlers are how that happens. Named explicitly rather than
# left to the wildcard so the decision is on the record and reversible: to opt
# out of model training while staying citable in answers, disallow GPTBot,
# ClaudeBot and Google-Extended and leave the -SearchBot agents allowed.
#
